# Developer & Agent Guidelines

## Server Lifecycle Rule
Whenever any changes or edits are made to the codebase (frontend or backend):
1. **Always restart all servers**:
   - Restart the Java Spring Boot backend (`http://localhost:8080`).
   - Restart the Next.js frontend (`http://localhost:3000`).
2. **Verify Server Health**:
   - Confirm both servers are responding with HTTP 200 after restarting.
